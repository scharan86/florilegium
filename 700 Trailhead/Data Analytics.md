# Data Analytics Trailhead
>[!Definition] 
>*Data Analytics* is the scientific process of converting raw data into insights for better decision making.

**Data Analytics** includes: [[Data Analysis]] + [[Modelling]] + [[Prediction]] + [[Optimization]]

e.g. What will be the sales next year? 

>[!question]- Why do data analytics and data analysis have to be separate?
>Understanding data (analysis) and acting on data (analytics) require different kinds of reasoning. Analysis reveals the relationships present in the dataset and  analytics uses it to build predictive or decision models.
