## Methods for Boolean Arrays

| Method            | Description                                       |
| ----------------- | ------------------------------------------------- |
| `(arr > 0).sum()` | Count True values (True coerces to 1, False to 0) |
| `bools.any()`     | True if one or more values are True               |
| `bools.all()`     | True if every value is True                       |
