>[!Definition]
> Recorded [[Measurement|measurements]] are called data.

e.g. 
```
Entities: Students
Variable: Heights
Measurement Process: Measuring Height
Data: {100cm,150cm,180cm}
```
## Intuition
It is a recorded value of a variable obtained through a standard measurement process. We find data to be useful because it gives us insights about the entity being measured and its behavior. 

- Data aids in: 
	1. Better decision making
	2. Evaluating performance
	3.  Identifying problems
	4. Improving processes
	5. Understanding customers
