>[!heuristic technique]
>*Heuristic* is a problem solving technique that trades optimality and completeness for for speed. In simpler terms, It involves employing a method that isn't fully optimized/perfect/rationalized but one that is good enough or an approximation. 

## Objective
To produce a solution in **reasonable time** that is good enough for solving a problem at hand.
## Heuristic Function
A *heuristic function (or heuristic)* is a function that ranks alternatives in [[Search Algorithms|search algorithms]] at each branch to decide which branch to follow.
