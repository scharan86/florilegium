>[!Definition]
> It sits at the root directory of a nodejs project.

It primarily does two things: 
1. Describes the project (name, version, description, author, license and other metadata) 
2. Declares the project dependencies (clone the repo and use this to install dependencies)

- The `name` and `version` serve as a unique identifier for the project.
