>[!Definition]
> In mathematics and statistics, a variable is a [[Symbolic Representation|symbolic representation]] of a value that can change.
> 
> In [[Data Analytics]], it the property or attribute of an entity that can take different values. 

## Intuition
It is a placeholder for something that has the capacity to change. It is used to refer to entities with dynamic values at any given time.  
```
Entity: Person
Variable: Age
Value: 0-120
```
