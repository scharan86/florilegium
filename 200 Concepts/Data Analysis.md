>[!Definition]
>It is a part of data analytics that focus on the understanding of existing data.

Data Analysis includes: [[Data Cleaning]], summarizing statistics, [[Data Visualization]] and [[Hypothesis Testing]]

e.g. What was the sales last year? 
## Intuition
Data analysis understands and explains the [[Dataset|dataset]]. It answers:
1. What changed?
2. Where did the drop occur? 
3. Where did the trend begin?

- [[Exploratory Data Analysis]] is a core analytical step.
