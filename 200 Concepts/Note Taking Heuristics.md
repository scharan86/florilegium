- Note-taking must be an outcome of understanding and not the other way around. 
- Atomic means one conceptual entity.
- A conceptual note must be atomic. 
- Every conceptual note should connect to at least one other conceptual note.
- Each note should largely answer one question, split it if it doesn't. 
- Notes should be atomic but complete, should include definition, intuition, explanation, properties and links.
- Explanations over transcription.

Conceptual notes should capture intuition explicitly:
1. Why the concept exists? 
2. What problem does it solve? 
3. How it behaves?
