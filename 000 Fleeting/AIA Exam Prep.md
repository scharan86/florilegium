
# AI Tasks

| Dimension               | Mundane task                                                                   | Formal task                                                           | Expert task                                                                |
| ----------------------- | ------------------------------------------------------------------------------ | --------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Definition              | Everyday routine tasks with common-sense reasoning and practical knowledge     | Well-defined tasks governed by explicit, structured rules and syntax  | Tasks requiring deep domain knowledge and heuristic judgment               |
| Knowledge type          | Common-sense, world knowledge; implicit and loosely structured                 | Formally defined rules, axioms, logical constraints                   | Specialized domain knowledge; experiential heuristics                      |
| Examples                | Understanding language, recognizing objects, navigating daily situations       | Chess, theorem proving, puzzle solving, game playing                  | Medical diagnosis, financial forecasting, legal reasoning, fault diagnosis |
| Problem space           | Vast, open-ended; context-dependent and ambiguous                              | Well-defined, finite, fully enumerable                                | Semi-structured; bounded but highly complex with uncertainty               |
| AI difficulty           | Very hard — the "AI-hard" category; hard to formalize                          | Relatively tractable; early AI successes (e.g. Deep Blue)             | Hard due to knowledge acquisition bottleneck and missing context           |
| Representation approach | Frames, scripts, semantic nets; attempts at common-sense ontologies (e.g. CYC) | Formal logic, state-space search, constraint satisfaction, game trees | Production rules, inference engines, decision trees, case-based reasoning  |
| Key challenge           | Frame problem; context sensitivity; world knowledge is enormous and implicit   | Combinatorial explosion in search space as complexity scales up       | Knowledge elicitation from experts; brittleness outside the trained domain |
| Reasoning style         | Analogical, associative, context-sensitive                                     | Exhaustive / heuristic search; deductive                              | Abductive and inductive; pattern matching against experience               |
