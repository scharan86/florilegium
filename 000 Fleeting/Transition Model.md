>[!Definition]
> A *Transition model* is a formal  description of how the world changes in response to actions — given a current state and an action, **it defines what the resulting state will be**.

- Transition model is the conceptual term and Result function is the operational term.
## Formal Definition
$$
RESULT(S, A) = S' \quad \text{where } S' \text{ is the state after applying action } A \text{ in state } S
$$
